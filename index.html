Simple notifications for the web.

Lightweight toast and popup notifications with built-in TypeScript support, Promise-based interactions, automatic light and dark mode, and no UI dependencies.

Try the demo View on GitHub
npm install notificate
Dependency-free No Bootstrap, icon library or UI framework required.
Promise-based Await toast actions and popup confirmations naturally.
Light & dark Automatically follows the user's preferred color scheme.

Quick start

Copy, paste and start using Notificate.

Browser 
<script src="https://unpkg.com/notificate@1"></script>

<script>
    Notificate.toast({
        title: 'Success',
        message: 'Operation completed successfully.',
        type: 'success'
    });
</script>
npm 
import { Notificate } from 'notificate';

Notificate.toast({
    title: 'Success',
    message: 'Operation completed successfully.',
    type: 'success',
});
